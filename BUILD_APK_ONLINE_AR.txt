بناء APK عبر GitHub Actions (سحابياً)

1) أنشئ حساباً أو سجّل الدخول إلى GitHub.
2) أنشئ مستودعاً جديداً باسم LOAY-ROBOT-CONTROL.
3) ارفع جميع محتويات هذا المجلد إلى المستودع، بما فيها المجلد المخفي .github.
   الأسهل: فك ضغط الملف ZIP على الكمبيوتر، ثم ارفع الملفات والمجلدات إلى المستودع.
4) افتح تبويب Actions في المستودع.
5) اختر Build LOAY ROBOT CONTROL APK ثم Run workflow.
   (أو سيبدأ البناء تلقائياً بعد رفع الملفات إلى فرع main).
6) انتظر انتهاء المهمة بنجاح، ثم افتح صفحة تشغيل الـ workflow.
7) ضمن Artifacts اضغط LOAY-ROBOT-CONTROL-APK لتنزيل ZIP يحتوي app-debug.apk.
8) فك ضغطه، وانقل app-debug.apk إلى Redmi وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

مهم:
- هذه عملية بناء سحابية؛ الملف APK لا يصبح موجوداً قبل نجاح GitHub Actions.
- هذا APK تجريبي Debug وليس إصداراً منشوراً على متجر.
- قبل تشغيل المحركات، يجب إكمال واختبار كود Arduino مع إيقاف آمن محلي عند فقد الاتصال.
